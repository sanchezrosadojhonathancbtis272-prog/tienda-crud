🛍️ ¿Qué es Tienda CRUD?

Tienda CRUD es una aplicación web desarrollada con Flask, Python y MongoDB, que permite administrar los productos de una tienda de manera sencilla.

El sistema permite registrar, consultar, actualizar y eliminar productos, además de ofrecer una API REST para gestionar la información mediante solicitudes HTTP.

⚙️ Operaciones principales

➕ CREATE - Crear

Permite registrar nuevos productos indicando su nombre, categoría, precio, cantidad, descripción e imagen.

📖 READ - Consultar

Muestra los productos registrados en MongoDB, incluyendo sus precios, categorías y existencias.

✏️ UPDATE - Actualizar

Permite modificar la información de un producto sin necesidad de eliminarlo y registrarlo otra vez.

🗑️ DELETE - Eliminar

Elimina del inventario un producto seleccionado, después de solicitar una confirmación.

📋 ¿Cómo utilizar la aplicación?

  1. Entra a Registrar producto.
  2. Completa el nombre, categoría, precio y stock. La descripción y la imagen son opcionales.
  3. Presiona Guardar producto.
  4. Consulta los artículos en la sección Productos.
  5. Utiliza Editar para actualizar la información.
  6. Utiliza Eliminar para quitar un producto del inventario.

🌐 API REST de productos

La aplicación incluye una API REST que permite gestionar productos mediante solicitudes HTTP y respuestas en formato JSON.

Método Ruta Función
GET /api/productos Consultar todos los productos
GET /api/productos/<id> Consultar un producto
POST /api/productos Crear un producto
PUT /api/productos/<id> Actualizar un producto
DELETE /api/productos/<id> Eliminar un producto
💡 Nota: Puedes probar las solicitudes GET desde el navegador. Para POST, PUT y DELETE puedes utilizar Postman o Thunder Client.

💻 Tecnologías utilizadas
